# Аптечка — план и структура

Семейное приложение для двух взрослых. Android-first PWA, позже — Play Market через Capacitor, потом iOS.
Бэкенд заменяемый: сейчас Google Таблица + Apps Script, потом — свой API без переписывания экранов.

## Структура

## Данные: миграция существующего листа

Текущий лист (без заголовков, ~183 строки):
`A` латинское название · `B` русское название (часто пусто) · `C` количество · `D` форма/единица.

Целевой лист «Лекарства», строка 1 — заголовки:

| колонка | откуда |
|---|---|
| id | генерируется (8 символов) |
| название | `A` — как написано на коробке |
| название_рус | `B` — добавленная колонка, чтобы не потерять русские названия; поиск ищет по обеим |
| действующее_вещество | пусто → дозаполняется ИИ по кнопке (только пустые ячейки) |
| форма | `D` с нормализацией («спрэй»→«спрей», «ампул»→«ампулы», «упаковка таблеток»→«таблетки», «бутылка»→«сироп», «шипучки»→«шипучие таблетки»; «флакон» остаётся) |
| дозировка | пусто |
| количество | `C` |
| срок_годности | пусто; формат текста `ГГГГ-ММ-ДД` |
| категория | пусто → дозаполняется ИИ по кнопке |
| для_кого | пусто → дозаполняется ИИ по кнопке (взрослый/детский/все) |
| место_хранения | пусто |
| заметка | пусто |
| обновлено | дата миграции |

Порядок: меню «Аптечка → 1. Сделать бэкап листа» (копия `Лекарства_backup_ГГГГ-ММ-ДД`) → «2. Мигрировать колонки» (только если нет заголовков — повторный запуск безопасен) → «3. Дозаполнить МНН и категории через ИИ» (пачками по 25, только пустые ячейки, ничего не перезаписывает).

## Бэкенд (Apps Script Web App)

- `POST` с `Content-Type: text/plain`, тело — JSON `{ token, action, payload }` → без CORS preflight.
- Ответ всегда JSON `{ ok: true, data } | { ok: false, error }`.
- Токен семьи — Script Property `FAMILY_TOKEN`, проверяется первым делом. Ключ Claude — `ANTHROPIC_API_KEY`, только в Script Properties.
- Экшены: `list`, `add`, `update`, `delete`, `ai` (`mode: extract | symptoms | prescription`).
- Запись под `LockService`, чтобы два телефона не затирали друг друга.
- Claude `claude-sonnet-5`, structured outputs (`output_config.format` с JSON-схемой) — фронт получает гарантированный JSON.
- В ИИ-запросы уходят только годные позиции: просроченные и с нулевым количеством отфильтровываются ещё в скрипте, промпт это дублирует.

## Экраны

1. Главный: поиск (по названию, русскому названию, МНН), бейджи «истекает срок» / «заканчивается», 8 плиток категорий с количеством.
2. Список: карточки, свайп влево — удалить с undo (5 с), тап — редактировать, +/- количество (оптимистично, запись с дебаунсом).
3. Добавить: «Сфотографировать коробку» → фото ужимается до 1600px → Claude vision → форма предзаполнена → «Сохранить». Ручной ввод — та же форма.
4. Помощник: «Что-то болит» (симптомы + для кого + возраст) и «Рецепт врача» (фото/текст). Ответ — карточки: точное совпадение / аналог по МНН с отличиями / нет дома → «купить».
5. Настройки: URL скрипта, токен, демо-режим, «Поделиться настройками» (ссылка для второго телефона).

## Дизайн

- Шрифт: Golos Text (кириллица, один семейство, веса 400/600/700), самохостинг через fontsource → работает офлайн.
- Палитра (светлая): фон `#F3F6F4`, поверхность `#FFFFFF`, текст `#15221C`, вторичный `#5E6E67`, акцент аптечный зелёный `#0E8A6D`, опасность `#C8402F`, предупреждение `#B9770E`.
  Тёмная: фон `#0F1613`, поверхность `#18221D`, текст `#E8EFEA`, вторичный `#93A39B`, акцент `#3DC79F`.
- У каждой категории свой тон (плитка + чип на карточке). Всё остальное — спокойное, один акцент.
- Кнопки и поля от 52px высотой, нижняя навигация 4 вкладки, крупные подписи. Без анимаций «ради красоты» — только отклик на действие.
- Тема по системе (`prefers-color-scheme`).

## Порядок реализации

1. Apps Script: миграция → CRUD → ИИ.
2. PWA: каркас, API-слой + демо-режим, экраны, свайпы, камера, помощник.
3. Иконки, манифест, офлайн-кэш.
4. Проверка на 390px скриншотами, тёмная тема.
5. README, GitHub Actions для Pages.
