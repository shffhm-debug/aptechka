# Аптечка

Домашняя аптечка семьи: PWA для Android + Google Таблица как база + Apps Script как бэкенд + Claude для распознавания коробок и подсказок.

- `web/` — приложение (React + Vite + Tailwind, PWA, офлайн-кэш последнего списка).
- `apps-script/` — код для редактора скриптов таблицы (эндпоинты `list / add / update / delete / ai`, миграция, ИИ).
- `PLAN.md` — архитектура, структура данных, дизайн.

Ключ Claude живёт только в Script Properties таблицы. На телефон он не попадает никогда.

---

## 1. Таблица и Apps Script

Таблица: «Домашняя аптечка (лекарства)». Сейчас в ней 4 колонки без заголовков; миграция ниже переводит её в 13 колонок и делает бэкап. Существующие данные не теряются.

### 1.1. Вставить код

1. Открой таблицу → меню **Расширения → Apps Script**.
2. В редакторе слева нажми **⚙ Настройки проекта** → включи галочку **«Показывать файл манифеста appsscript.json в редакторе»**.
3. Вернись в «Редактор». Замени содержимое `Code.gs` на файл `apps-script/Code.gs`.
4. Через **«+» → Скрипт** создай файлы `Ai`, `Prompts`, `Migration` и вставь в них содержимое одноимённых файлов из `apps-script/`.
5. Открой `appsscript.json` и замени содержимое на `apps-script/appsscript.json`.
6. **Сохрани** (Ctrl+S).

### 1.2. Ключ Claude

1. **⚙ Настройки проекта → Свойства скрипта → Добавить свойство**.
2. Имя `ANTHROPIC_API_KEY`, значение — ключ из [console.anthropic.com](https://console.anthropic.com/) (начинается с `sk-ant-`).
3. Сохранить.

Модель — `claude-sonnet-5` (константа `CLAUDE_MODEL` в `Ai.gs`).

### 1.3. Семейный токен и миграция

Закрой и снова открой таблицу (или обнови страницу). Появится меню **«Аптечка»**.

1. **Аптечка → Создать семейный токен.** При первом запуске Google попросит разрешения: «Дополнительные настройки → Перейти к проекту → Разрешить». Токен покажется в окне и сохранится в Script Properties. Запиши его — его вводят в приложении.
2. **Аптечка → 1. Сделать бэкап листа.** Появится лист `Лекарства_backup_ГГГГ-ММ-ДД`. Не трогай его.
3. **Аптечка → 2. Мигрировать колонки.** Лист переименуется в `Лекарства`, добавится строка заголовков:

   `id · название · название_рус · действующее_вещество · форма · дозировка · количество · срок_годности · категория · для_кого · место_хранения · заметка · обновлено`

   Старые колонки перейдут так: A → `название`, B → `название_рус`, C → `количество`, D → `форма` (с нормализацией: «спрэй» → «спрей», «ампул» → «ампулы», «упаковка таблеток» → «таблетки», «бутылка» → «сироп», «шипучки» → «шипучие таблетки»; «флакон» остаётся). Остальное пусто.
4. **Аптечка → 3. Дозаполнить МНН и категории через ИИ.** Claude проставит действующее вещество, категорию и «для кого» — только в пустые ячейки, пачками по 25. Позиции с низкой уверенностью помечаются в `заметка` как «ИИ не уверен — проверь». Занимает 2–3 минуты. Можно запускать повторно.
5. **Аптечка → Проверить настройки** — покажет, что задано, и сделает тестовый запрос к Claude.

Все три шага безопасно запускать повторно: миграция не тронет лист с заголовками, дозаполнение не перезаписывает заполненное.

### 1.4. Опубликовать Web App

1. **Начать развёртывание → Новое развёртывание → ⚙ Тип: Веб-приложение.**
2. **Запуск от имени:** «Я». **У кого есть доступ:** «Все» (иначе телефоны не смогут обращаться к скрипту; защита — семейный токен).
3. **Начать развёртывание** → скопируй **URL веб-приложения** (заканчивается на `/exec`).

После любого изменения кода: **Начать развёртывание → Управление развёртываниями → ✎ → Версия: «Новая версия» → Развернуть.** URL при этом не меняется.

Формат запросов: `POST` с `Content-Type: text/plain`, тело — JSON `{ token, action, payload }`. Так браузер не делает CORS preflight, и Apps Script отвечает напрямую.

## 2. Приложение (PWA)

### Локально

```bash
cd web
npm install
npm run dev
```

Открой адрес из консоли. В настройках можно включить **демо-режим** — данные в localStorage, ИИ отвечает заготовками — чтобы посмотреть экраны без таблицы.

### Деплой на GitHub Pages (рекомендуется)

1. Создай репозиторий на GitHub (можно приватный — Pages для приватных репо доступен на платных планах; для бесплатного делай публичный: в коде нет секретов) и запушь папку целиком.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. Workflow `.github/workflows/pages.yml` уже есть: при каждом push в `main` он собирает `web/` и публикует. Приложение появится по адресу `https://<логин>.github.io/<репозиторий>/`.

### Деплой на Cloudflare Pages (альтернатива)

Workers & Pages → Create → Pages → подключить репозиторий. **Build command:** `npm run build`, **Root directory:** `web`, **Output directory:** `dist`. Переменная `BASE_PATH` не нужна (приложение в корне домена).

### Установить на Android

1. Открой адрес приложения в **Chrome** на телефоне.
2. Меню **⋮ → «Установить приложение»** (или «Добавить на главный экран»). Иконка появится рядом с обычными приложениями и откроется без адресной строки.
3. Запусти → **Настройки**: вставь **адрес скрипта** (`/exec`) и **семейный токен** → **Проверить связь** → **Сохранить**.
4. На втором телефоне: в настройках первого нажми **«Поделиться настройками»** — откроется системное «поделиться» со ссылкой. Открой её на втором телефоне, нажми «Сохранить», затем установи приложение так же через ⋮.

Список кэшируется: без интернета приложение откроется и покажет последнее состояние. Добавление, правки и помощник требуют сети.

### Android-оболочка (APK)

Кроме PWA есть нативная оболочка на Capacitor (`web/android/`). Это WebView, который открывает тот же сайт с GitHub Pages, поэтому обновления приложения прилетают без переустановки APK. Камера для фото коробок работает через системный выбор файла.

Установить: скачать `aptechka-debug.apk` из [Releases](https://github.com/shffhm-debug/aptechka/releases/latest) на телефон, открыть файл, разрешить установку из этого источника. При первом запуске адрес скрипта уже подставлен, нужно ввести только семейный токен и нажать «Сохранить».

Пересобрать APK (нужны Android Studio с SDK и её JDK):

```bash
cd web
npm run build && npx cap sync android
cd android && JAVA_HOME="C:/Program Files/Android/Android Studio/jbr" ./gradlew assembleDebug
# результат: android/app/build/outputs/apk/debug/app-debug.apk
```

Иконки и заставка генерируются из `web/assets/` командой `npx capacitor-assets generate --android`. Для Play Market нужна подписанная release-сборка (`assembleRelease` с keystore) и аккаунт разработчика.

## 3. Как это устроено

**Экраны.** Главный — поиск (ищет по названию, русскому названию и МНН; «нурофен» находит «nurofen»), бейджи «просрочено / истекает срок / заканчивается», плитки категорий. Список — карточки, свайп влево удаляет (с «Вернуть» на 6 секунд), тап открывает, «−/+» меняет количество сразу и записывает в таблицу через секунду. Добавить — «Сфотографировать коробку»: фото ужимается до 1600 px, уходит в Apps Script → Claude → поля заполняются, ты проверяешь и жмёшь «Сохранить». Помощник — «Что-то болит» и «Рецепт врача».

**Бейджи.** «Истекает срок» — 30 дней до даты. «Заканчивается» — 0 упаковок, либо 1 штука для ампул, пакетиков, свечей, шипучих таблеток, порошков, пластырей (для таблеток «1 упаковка» — норма).

**Правила ИИ** зашиты в `apps-script/Prompts.gs` (`SAFETY_RULES`): аналог только по тому же действующему веществу с явными отличиями; замена на другое вещество — только пометка «обсудить с врачом»; просроченное и с нулевым количеством в ИИ вообще не отправляется (фильтр в `Ai.gs`); возраст ребёнка учитывается; предупреждение о дублировании вещества; тревожные симптомы — сначала «за помощью»; в каждом ответе строка «Это подсказка, а не замена врачу». Ответы — строго JSON по схеме (structured outputs), фронт рисует карточками.

**Смена бэкенда.** Весь обмен с сервером — в `web/src/api/client.js`. Чтобы переехать на свой API (аккаунты, подписка, магазины), меняется только этот файл и код в `apps-script/` заменяется сервером. Экраны, состояние и логика не трогаются. Для Play Market приложение заворачивается в Capacitor: `npx cap init` в `web/`, `npx cap add android`, `npm run build && npx cap sync` — камера через `<input capture>` в WebView работает как есть.

## 4. Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| «Сервер вернул не JSON» | URL не заканчивается на `/exec`, либо в развёртывании доступ не «Все». Переразверни. |
| «Неверный семейный токен» | Токен в приложении не совпадает со Script Property `FAMILY_TOKEN`. Меню Аптечка → «Создать семейный токен» покажет текущий. |
| «Таблица не готова: sheet_not_migrated» | Не выполнен шаг 2 миграции. |
| «Ошибка ИИ (401)» | Ключ `ANTHROPIC_API_KEY` неверный. «Ошибка ИИ (400)» — смотри текст: чаще всего слишком большое фото или несуществующая модель. |
| Изменил код, а поведение старое | Не создана новая версия развёртывания (см. 1.4). |
| Распознавание идёт больше минуты и падает | Apps Script ждёт ответ ограниченное время. Уменьши `effort` в `Ai.gs` до `low` для `aiSymptoms/aiPrescription`. |
| Кто-то узнал токен | Смени значение `FAMILY_TOKEN` в Script Properties и введи новый на телефонах. |
| Список внезапно пустой или «Сервер ответил невпопад» | Apps Script иногда ломает цепочку редиректов: POST превращается в GET или echo отдаёт 404. Клиент проверяет форму ответа и повторяет запрос до 3 раз, кэш при этом не затирается. Если повторяется часто, просто открой приложение ещё раз. |

**Безопасность.** Web App с доступом «Все» защищён только токеном: без него сервер отвечает `unauthorized` и ничего не делает. Ключ Claude из скрипта никуда не отдаётся. Токен на телефоне лежит в localStorage приложения.
